# Coffeella Café — المنيو

منيو كوفيلا كافيه (بغداد – حي الجامعة): موقع ثابت سريع يعمل على الجوال والحاسوب، بديل محسّن لصفحة Google Sites الأصلية.

## ما الجديد مقارنةً بالموقع الأصلي

- الأسعار نص حقيقي بدل صور (قابلة للبحث والقراءة على أي شاشة).
- بحث فوري بالعربي أو الإنجليزي يتسامح مع (أ/ا، ة/ه، ى/ي) والأرقام العربية.
- كل الأقسام في صفحة واحدة مع شريط تنقل مثبّت يتابع القسم الحالي.
- شعار البراند وصور كوفيلا الأصلية، مع روابط مباشرة للاتصال وواتساب وانستغرام.

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `index.html` | هيكل الصفحة ومعلومات التواصل |
| `styles.css` | التصميم والألوان |
| `app.js` | عرض المنيو والبحث والتنقل |
| `menu-data.js` | **الأصناف والأسعار** — عدّل هذا الملف لتغيير المنيو |
| `assets/` | شعار البراند وصور الأقسام |

## تعديل الأسعار

افتح `menu-data.js` وغيّر قيمة `price` للصنف:

```js
{ ar: "لاتيه", en: "Latte", price: [4000, 5000] }  // مدى سعري
{ ar: "إسبريسو", en: "Espresso", price: 3000 }      // سعر واحد
```

## التشغيل

لا يحتاج الموقع أي أدوات بناء؛ انشر المجلد كما هو على أي استضافة ثابتة (مثل GitHub Pages).
